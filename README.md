# Бот интенсива «AI-старт»

Принимает участников после оплаты и по тарифу Стандарт, и по VIP, кидает их в канал мероприятия,
собирает базу в Google Sheets, начисляет реферальные бонусы и делает апсейл.

## Файлы в репозитории (все обязательны)

- `bot.py` — основной файл бота, точка входа
- `config.py` — чтение переменных окружения
- `keyboards.py` — инлайн-кнопки
- `texts.py` — тексты сообщений
- `sheets.py` — работа с Google Sheets
- `requirements.txt` — зависимости для установки на Railway
- `Procfile` — команда запуска для Railway (`worker: python bot.py`)
- `.env.example` — шаблон переменных окружения для локального теста

## Что вставить в Railway → Variables

Идёшь в проект на Railway → вкладка **Variables** → добавляешь каждую строку отдельной переменной:

| Переменная                    | Значение                                                        |
| ------------------------------ | ----------------------------------------------------------------- |
| `BOT_TOKEN`                   | токен бота от @BotFather                                          |
| `ADMIN_IDS`                   | твой telegram_id (узнать у @userinfobot), можно несколько через запятую |
| `ADMIN_LOG_CHAT_ID`           | числовой ID канала-журнала (опционально)                          |
| `EVENT_CHANNEL_INVITE`        | постоянная ссылка на канал мероприятия для тарифа **Стандарт**    |
| `VIP_CHANNEL_INVITE`          | постоянная ссылка на VIP-канал                                    |
| `GOOGLE_SHEET_ID`             | ID твоей таблицы из URL                                           |
| `GOOGLE_SERVICE_ACCOUNT_JSON` | весь JSON сервисного аккаунта одной строкой (см. ниже)            |
| `VIP_UPGRADE_LINK`            | ссылка на оплату VIP (для апсейла тем, кто на Стандарте)          |
| `FLAGSHIP_COURSE_LINK`        | ссылка на флагманский курс (для апсейла VIP)                      |

`EVENT_CHANNEL_ID` и `VIP_CHANNEL_ID` можно не заполнять — это опция для одноразовых
инвайт-ссылок через API. Без них бот просто отправляет постоянную ссылку из
`EVENT_CHANNEL_INVITE` / `VIP_CHANNEL_INVITE`, этого достаточно для старта.

⚠️ Если токен бота когда-либо публиковался в переписке/чате — перевыпусти его через
@BotFather → `/revoke` → `/token` и вставь новый в Railway.

## Как это работает: два канала

- Тариф **Стандарт** (код `free`) → ведёт в канал мероприятия (`EVENT_CHANNEL_INVITE`)
- Тариф **vip** → ведёт в отдельный VIP-канал (`VIP_CHANNEL_INVITE`)

На сайте / в форме оплаты кнопки «спасибо за оплату» ведут на бота:

- тариф Стандарт → `https://t.me/ТВОЙБОТ?start=free`
- VIP тариф → `https://t.me/ТВОЙБОТ?start=vip`

Дальше по шагам:

1. Бот пишет пользователя в Google Sheets, выдаёт ссылку на нужный канал и его личную
   реферальную ссылку вида `https://t.me/ТВОЙБОТ?start=free_ref_123456789`.
2. Если по этой ссылке пришёл друг, рефереру начисляется +1 к счётчику, и при достижении
   порога (1 / 3 / 5 / 10 друзей) бот сам присылает уведомление о бонусе.
3. Через 3 часа после регистрации бот присылает апсейл (задержку правишь в `bot.py`,
   переменная `delay_seconds`).
4. Команда `/broadcast текст` (только для админов из `ADMIN_IDS`) — рассылка по всей базе.
5. Команда `/moi_ref` — пользователь может посмотреть свою реферальную ссылку и счётчик.

## Настройка Google Sheets

1. Создай таблицу в Google Sheets, скопируй её ID из URL
   (`https://docs.google.com/spreadsheets/d/ЭТОТ_ID/edit`).
2. В Google Cloud Console создай проект → включи **Google Sheets API** и **Google Drive API**.
3. Создай сервисный аккаунт (Service Account) → создай для него JSON-ключ, скачай файл.
4. Открой скачанный JSON, найди там `client_email`, открой доступ к таблице на этот email
   с правами **Редактор**.
5. Вставь содержимое JSON-файла одной строкой в переменную `GOOGLE_SERVICE_ACCOUNT_JSON`
   на Railway.

Лист «Users» бот создаст сам при первом запуске.

## Деплой на Railway

1. Залей все файлы из этого репозитория в GitHub-репозиторий (полностью, включая
   `requirements.txt` и `Procfile` — без них бот не соберётся и не запустится).
2. На Railway: New Project → Deploy from GitHub repo.
3. В разделе Variables добавь все переменные из таблицы выше.
4. Railway подхватит `Procfile` и запустит `python bot.py`.
5. Проверь логи деплоя: должно быть `Google Sheets подключены` и `Бот запущен`.
   Если видишь ошибку — она подробно объясняет, что не так (обычно это права
   доступа к таблице или неверный JSON).

## Локальный запуск для теста

```
pip install -r requirements.txt
cp .env.example .env    # заполнить своими значениями
python bot.py
```

## Что стоит донастроить под себя

- Тексты сообщений — в `texts.py`.
- Пороги и бонусы за рефералов — в `config.py`, список `REFERRAL_TIERS`.
- Время апсейла (сейчас 3 часа после регистрации) — в `bot.py`, переменная `delay_seconds`.
- Выдача бонусов сейчас полуручная: бот присылает тебе в личку заявку, когда человек
  пишет «забрать бонус». Автоматизировать (например, автовыдачу PDF) можно позже.
