# Бот интенсива «AI-старт»

Принимает и бесплатных, и VIP-участников после оплаты, кидает их в канал мероприятия,
собирает базу в Google Sheets, начисляет реферальные бонусы и делает апсейл.

## Что вставить в Railway → Variables (конкретно под тебя)

Идёшь в проект на Railway → вкладка **Variables** → добавляешь каждую строку отдельной переменной:

| Переменная | Значение |
|---|---|
| `BOT_TOKEN` | `8637414059:AAG3uIYTqJ9uZq9KwfO4UWgT1h1JVVEuji0` |
| `ADMIN_IDS` | твой telegram_id (узнать у @userinfobot) |
| `EVENT_CHANNEL_INVITE` | постоянная ссылка на канал мероприятия для **бесплатного** тарифа |
| `VIP_CHANNEL_INVITE` | `https://t.me/+gsOVvl1OfpEyZGYy` |
| `GOOGLE_SHEET_ID` | ID твоей таблицы из URL |
| `GOOGLE_SERVICE_ACCOUNT_JSON` | весь JSON сервисного аккаунта одной строкой (см. ниже) |
| `VIP_UPGRADE_LINK` | ссылка на оплату VIP (для апсейла бесплатным) |
| `FLAGSHIP_COURSE_LINK` | ссылка на флагманский курс (для апсейла VIP) |

`EVENT_CHANNEL_ID` и `VIP_CHANNEL_ID` **можно не заполнять** — это опциональная штука
для одноразовых ссылок-приглашений (чтобы видеть, кто именно перешёл, и ограничивать
ссылку одним использованием). Без них бот просто отправляет постоянную ссылку из
`EVENT_CHANNEL_INVITE` / `VIP_CHANNEL_INVITE` — этого достаточно для старта.

⚠️ Токен бота уже был один раз показан в переписке — это не критично, но если хочешь
подстраховаться, можно перевыпустить его через @BotFather → `/revoke` → `/token`
и вставить новый в Railway.

## Как это работает: два канала

- Тариф **free** → ведёт в канал мероприятия (`EVENT_CHANNEL_INVITE`)
- Тариф **vip** → ведёт в отдельный VIP-канал (`VIP_CHANNEL_INVITE`)

На сайте / в форме оплаты кнопки «спасибо за оплату» ведут на бота:
- бесплатный тариф → `https://t.me/ТВОЙБОТ?start=free`
- VIP тариф → `https://t.me/ТВОЙБОТ?start=vip`

Бот сам разбирает параметр `start` и присылает нужную ссылку.

Дальше по шагам:

2. Бот пишет пользователя в Google Sheets, выдаёт ссылку на нужный канал и его личную реферальную ссылку
   вида `https://t.me/ТВОЙБОТ?start=free_ref_123456789`.
3. Если по этой ссылке пришёл друг — рефереру начисляется +1 к счётчику, и при достижении порога
   (1 / 3 / 5 / 10 друзей) бот сам присылает уведомление о бонусе.
4. Через 3 часа после регистрации бот присылает апсейл:
   - бесплатным — предложение перейти на VIP,
   - VIP-участникам — предложение на флагманский курс.
   (Задержку правишь в `bot.py`, переменная `delay_seconds`.)
5. Команда `/broadcast текст` (только для админов из `ADMIN_IDS`) — рассылка по всей базе.

## Настройка Google Sheets

1. Создай таблицу в Google Sheets, скопируй её ID из URL
   (`https://docs.google.com/spreadsheets/d/ЭТОТ_ID/edit`).
2. В Google Cloud Console создай проект → включи **Google Sheets API** и **Google Drive API**.
3. Создай сервисный аккаунт (Service Account) → создай для него JSON-ключ, скачай файл.
4. Открой сгенерированный JSON, найди там `client_email` — открой доступ к таблице
   на этот email с правами **Редактор**.
5. Положи скачанный JSON-файл в проект как `service_account.json`
   (или вставь его содержимое одной строкой в переменную `GOOGLE_SERVICE_ACCOUNT_JSON` на Railway).

Лист «Users» бот создаст сам при первом запуске.

## Деплой на Railway

1. Залей папку в GitHub-репозиторий.
2. На Railway: New Project → Deploy from GitHub repo.
3. В разделе Variables добавь все переменные из `.env.example` (реальные значения).
4. Если используешь JSON-ключ как файл — просто добавь `service_account.json` в репозиторий
   (в `.gitignore` не добавляй, но и не публикуй репозиторий, если он приватный — ок; если публичный,
   лучше вставить JSON в переменную окружения, а не коммитить файл).
5. Railway подхватит `Procfile` и запустит `python bot.py`.

## Настройка канала мероприятия

1. Добавь бота в канал как администратора с правом **«Приглашать пользователей по ссылке»**.
2. В `EVENT_CHANNEL_ID` укажи числовой ID канала (можно узнать через @userinfobot, переслав туда
   любое сообщение из канала, либо через @getidsbot).
3. `EVENT_CHANNEL_INVITE` — запасная публичная ссылка на случай, если создание инвайта через API
   не сработает (например, права не выданы).

## Локальный запуск для теста

```bash
pip install -r requirements.txt
cp .env.example .env    # заполнить своими значениями
python bot.py
```

## Что стоит донастроить под себя

- Текст сообщений — в `texts.py`, весь тон уже без маркетингового пафоса, но поправь под голос.
- Пороги и бонусы за рефералов — в `config.py`, список `REFERRAL_TIERS`.
- Время апсейла (сейчас 3 часа после регистрации) — в `bot.py`, `delay_seconds`.
- Выдача бонусов сейчас полуручная: бот присылает тебе в личку заявку, когда человек пишет
  «забрать бонус» — это нормально для старта, автоматизировать (например, автовыдачу PDF)
  можно позже, когда будет понятен объём.
